# Phase 0 Checklist

## Scope

- macOS SwiftUI app skeleton
- Basic window content
- Core module for testable non-UI code
- Test target with smoke coverage
- Placeholder folders for models, services, view models, views, and tests

## Automated Verification

- `swift test`
- `swift run LocalClassroomSmokeTests`
- `swift build`

## Manual Verification

- App launches.
- Main window appears.
- Temporary home screen is visible.
- App does not crash.
